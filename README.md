## Hi, I'm Andrii

I build small, self-contained mobile games for Android — Kotlin, Jetpack Compose and libGDX, no game-engine editor, everything from the game loop and physics up to the UI, art pipeline and release packaging.

Below are 14 shipped builds. Every repository has its own README with screenshots, the real tech stack and build instructions.

### Games

| Game | What it is |
| --- | --- |
| **[Volcanix](https://github.com/brah1995u/volcanix)** | Volcanic marble shooter — match colored orbs into a moving magma chain before it reaches the crater. |
| **[Avia Aces](https://github.com/brah1995u/avia-aces)** | Vertical-scrolling arcade shoot-'em-up across 90 levels of cartoon sky-pirate skies. |
| **[Zeuzzle Merge 2048](https://github.com/brah1995u/zeuzzle)** | Mythological merge puzzle — 2048 logic on an Olympus board, with campaign, Endless and score-attack modes. |
| **[Gummy Puzzle Drop](https://github.com/brah1995u/gummy-puzzle-drop)** | Falling-block puzzle where four-cell shapes clear through Match-3, not full rows. |
| **[Frostline Fishing](https://github.com/brah1995u/frostline-fishing)** | Ice-fishing arcade — lure, hook and reel across 90 levels in six frozen worlds. |
| **[Thunder Stack](https://github.com/brah1995u/thunderstack)** | Block-stacking on the path to Olympus, scored on support ratio, overhang and lean. |
| **[Red Sky](https://github.com/brah1995u/red-sky)** | One-touch aviation arcade — hold to dive, release to climb, gamble on the REDLINE multiplier. |
| **[Frozen Path](https://github.com/brah1995u/frozen-path)** | Routing puzzle — flip two-state junctions to send fish and junk to their matching sinks. |
| **[Frost Catch](https://github.com/brah1995u/frost-catch)** | Offline fishing action — three live rods at once, timing strikes across 30 icy lakes. |
| **[Road Rooster](https://github.com/brah1995u/road-rooster)** | Arcade runner about reading timing and lane choice on an increasingly chaotic road. |
| **[Candy Rail](https://github.com/brah1995u/candy-rail)** | Sorting arcade — tap a rail junction to route sweets into three matching carts. |
| **[FRUSLASH](https://github.com/brah1995u/fruslash)** | Fruit-slicing arcade with combo chains and a lives system. |
| **[Fruvio](https://github.com/brah1995u/fruvio)** | Fruit-merge physics puzzle plus a hub of three fruit-themed mini-games. |
| **[Flame Jester](https://github.com/brah1995u/flame-jester)** | 3x3, 5-payline video slot demo with a fire-and-fruit carnival theme (fun coins only). |

### Tech

**Kotlin** · **Jetpack Compose** · **libGDX** · **Box2D** · **Gradle (Kotlin DSL)** · **Android SDK**

Also working with **TypeScript**, **React** and **Next.js** on the web side, and with **n8n** for automation pipelines.
